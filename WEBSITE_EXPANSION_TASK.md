# Cursor Task — Expand the Existing YAT-YAS Website Without Redesigning It

## Non-negotiable design constraint

**The current website already looks good. Do not redesign it.**

Preserve the existing:

- logo and logo placement
- color palette
- typography
- header/navigation behavior
- hero treatment
- spacing system
- card style
- button style
- section rhythm
- mobile responsiveness
- footer
- animations and motion language
- existing photography/visual treatment
- overall corporate, professional tone

Do not replace the existing homepage with a new concept. Do not introduce a new design system. Do not change the logo. Do not add military clip art, vehicle illustrations, novelty graphics, or anything that makes the site feel like a hobby club.

The task is to **integrate the new Association vision into the existing site so it feels as though it was always part of the design**.

Before making changes, inspect the current page structure and reusable components. Reuse existing components wherever possible. If a section already communicates part of the content below, improve or extend it instead of duplicating it.

## Brand and positioning

Legal/public organization:

**YAT-YAS Association**

Official domain:

**YATYASLegacy.com**

Primary working positioning:

**One Brotherhood. Every Generation.**

Lineage:

**LVT → LVTP → AAV → ACV**

Supporting brand lines that may be used sparingly where they fit:

- Steel. Surf. Brotherhood. Legacy.
- The machines changed. The brotherhood didn't.

Do not overcrowd the hero with multiple slogans. Preserve the current hero first. If the current hero can accommodate one subtle supporting line without changing its composition, use **One Brotherhood. Every Generation.** Otherwise place it immediately below the hero.

## Website goal

The website must show that YAT-YAS is not just a reunion club or dues organization.

It should communicate a living national network built around four pillars:

1. Brotherhood
2. Legacy
3. Next Mission
4. Family

The site should make an active-duty Marine, veteran, retiree, spouse, descendant, or supporter understand why the Association exists and why membership matters.

### 5. Add flagship programs

Use the current site's visual rhythm. Do not create a giant wall of cards.

**Programs That Carry the Legacy Forward**

#### Final Splash

#### YAT-YAS Heritage Map
