# YAT-YAS Association — Launch Roadmap

Status: Working roadmap. Legal formation and tax/compliance work take priority over optional software features.

## Phase 0 — Form the corporation

Objective: establish the legal and governance foundation.

- file California Articles of Incorporation
- receive entity number and accepted Articles
- obtain EIN
- hold organizational Board action
- adopt bylaws
- appoint required officers
- adopt membership, conflict, compensation, and financial controls
- file Statement of Information
- open Association bank account
- prepare federal 501(c)(19) application
- pursue California exemption
- address Attorney General registration if applicable

Exit condition: YAT-YAS can operate through an approved governance and financial framework.

## Phase 1 — Founding launch

Objective: create a credible public presence and begin the Founding 100.

- finalize corporate logo and brand system
- launch YATYASLegacy.com public site
- publish mission and four pillars
- publish independent/non-DoD disclaimer
- create Founding 100 page
- create membership application workflow
- create secure service-verification process
- establish dues payment process
- issue member numbers
- create digital membership card MVP
- recruit Founding Charter Members 001–100

Key principle: do not accept or publicly store sensitive verification documents through GitHub.

## Phase 2 — Brotherhood MVP

Objective: make membership useful beyond dues.

- member profiles
- Crew Finder
- event calendar
- Breakfast Club registration
- chapter interest map
- volunteer opportunities
- Track-to-Next-Mission mentor enrollment

## Phase 3 — Legacy MVP

Objective: begin building the permanent historical record.

- Oral History Project intake
- searchable transcripts
- Final Splash memorial
- Legacy Registry
- historical photograph intake
- museum/restoration partner page
- basic Heritage Map

## Phase 4 — National network

Objective: create repeatable programs and chapter operations.

- inaugural YAT-YAS Muster
- formal chapter framework
- chapter leadership toolkit
- scholarship pilot
- Emergency Brotherhood Fund policy and pilot
- museum/restoration micro-grants when financially sustainable
- family and Legacy Member programming

## Phase 5 — Mature digital association

Objective: operate as a durable national member institution.

- secure electronic voting
- annual member report
- chapter reporting
- mentorship metrics
- integrated archive search
- AI-assisted oral-history indexing
- advanced Heritage Map
- cross-linked people/unit/location/platform history
- program-impact dashboard

## Launch priorities

Do first:

1. formation
2. governance
3. banking and compliance
4. Founding 100 membership system
5. public site
6. basic member portal

Do not let these block initial launch:

- full AI archive
- advanced Heritage Map
- complex chapter software
- scholarship automation
- emergency-fund automation
- elaborate social features

## Recommended first-year targets

These are planning targets, not promises:

- complete legal formation and exemption submissions
- fill the Founding 100
- record the first 25 oral histories
- establish at least three recurring Breakfast Club locations
- run the first mentorship cohort
- launch Final Splash
- hold or announce the inaugural YAT-YAS Muster
- document one museum/restoration partnership
- publish a first annual Association impact report
